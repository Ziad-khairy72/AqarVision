# AqarVision 🏡

**🏡 Egypt Real Estate Price Prediction & Azure ML Lifecycle System ☁️**

AqarVision is an end-to-end Machine Learning project developed as part of the Digital Egypt Pioneers Initiative (DEPI) - Microsoft ML Engineer track. The system aims to predict the fair market value of real estate properties in Egypt based on various features. Furthermore, it implements a complete cloud-based ML lifecycle on Azure ML, including experiment tracking with MLflow, model registration, and endpoint deployment.
